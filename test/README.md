# test/

**Все** тесты проекта.

**Правило:** тестовые файлы **только** здесь, в корне — не размещать.


## Планируемые тесты


- `test\_event.py` — слушатели блокчейна (мок)

- `test\_delivery.py` — транспорты (MQTT, файл)

- `test\_executor.py` — сборка пакета

- `test\_packet.py` — формат пакета TUR55



## Запуск



```powershell
py -m pytest test -v
```
