# inputfiles/

Шаблоны Python-скриптов для ESP32.

В эти шаблоны Executor **встраивает** данные из смарт-контракта
(`user_wallet`, `amount`, `expires`, `custom_data`).

## Примеры

- `led_control.py` — мигание LED
- `unlock.py` — открытие замка
- `sensor_read.py` — чтение датчика
